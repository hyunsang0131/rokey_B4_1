# 커버(뚜껑) 열기/닫기 코드 설명

2026-11-19 기준 (데모 구조 반영판, 롤러 단계 삭제 후 9단계 공정). 코드: `silicone-bed/bed_inspect/` (`bed_inspect.zip`도 갱신).

## 1. 데모 동작을 그대로 따른다

형님 설명대로 짰습니다.
1. 고리 바로 위에서 툴 Z를 수직으로 맞추고, 수직으로 내려가 고리를 잡습니다.
2. **시작점 → 경유점: 원호(moveC)**. 이 동안 툴은 거의 수직입니다.
3. **경유점 → 끝점: x는 그대로 두고 y와 z만 바꾸는 직선 이동**입니다(moveC 아님). 데모처럼 고리를 계속 쥔 채로 가되, 이 구간에서는 **살며시** 잡습니다(그리퍼 폭 `GRIP_WIDTH['cover_loose']` = 20mm, 원호 동안은 `cover_grip` = 10mm).
4. 끝점에서 그리퍼를 놓으면 뚜껑이 베드 옆면의 약 110도 받침에 걸쳐 고정됩니다. 그 뒤 실리콘 교체 등의 작업을 합니다.

## 2. 경첩 위치와 좌표 계산 (`bed_math.cover_path`)

경첩 위치는 직접 잴 수 없어서 데모에서 계산했습니다.
- 닫힌 뚜껑은 수평이고 경첩은 고리와 같은 높이에 있다고 가정했습니다(경첩 z = 시작점 z 117.92).
- 원호 구간에서는 시작점과 경유점이 경첩에서 같은 거리에 있으므로, 경첩은 **y -240.4, z 117.9**입니다. 축은 베이스 X 방향입니다.
- 이 경첩에서 보면 데모 경유점은 **35.8도**, 데모 끝점은 **102.7도**입니다. 끝점은 원보다 4% 바깥에 있습니다(데모에서 살짝 당긴 만큼).

고리를 y -50에서 잡으면 같은 경첩 둘레로 반지름만 190.4mm(데모 224.3mm)로 바뀝니다.
- 경유점: 같은 35.8도 위치, 데모 경유 자세
- 끝점: 같은 102.7도, 같은 4% 바깥, 데모 끝 자세
- **x는 처음부터 끝까지 576.28**(4번 블록 중심 x이자 경첩 두 개의 가운데)입니다.
- 끝점 z는 311로 데모(345)보다 34mm 낮습니다. 고리가 경첩에 34mm 더 가까워서(y -50 대 -16), 같은 각도까지 열면 그만큼 덜 올라가기 때문입니다. 고리를 데모와 같은 y -16에서 잡으면 데모 끝점 z 345가 그대로 나옵니다.

## 3. 경유점 → 끝점 직선을 3개로 나눈 이유 (`COVER_LINE_SEGMENTS`)

경유점(36도)에서 끝점(103도)까지 **한 번에 직선**으로 가면, 직선이 경첩 원의 안쪽을 가로지릅니다. 가운데에서 원보다 **약 32mm**(데모 반지름이면 37mm) 경첩 쪽으로 파고듭니다. 고리를 경첩 쪽으로 3cm 미는 셈입니다.
데모에서 문제가 없었던 것은 고리가 손가락에 걸려 있어서 놀이가 있었기 때문이라고 봅니다. 포맥스 뚜껑이 깨질 위험을 줄이려고 기본값을 **3개로 나눴습니다**. 각 구간은 여전히 x 고정에 y·z만 바꾸는 직선이고, 원에서 최대 약 4mm만 벗어납니다.
데모와 똑같이 한 번에 가려면 `COVER_LINE_SEGMENTS = 1`로 바꾸면 됩니다.

가짜 경첩으로 잰 최대 외력(순응 제어 켬, 한계 20N):

| 직선 | 고리 놀이 25mm | 고리를 꽉 물었을 때 |
|---|---|---|
| 3개로 나눔(기본) | 0N | 7.6N (끝점을 4% 바깥으로 당기는 몫) |
| 한 번에(데모 그대로) | 3.5N | 20N에서 **정지**(파손 전) |

## 4. 동작 순서 (`bed_tasks.py`)

**4단계 열기**: 그리퍼 열기 → 홈 → above(60mm/s) → 수직 하강 grip(10mm/s) → 잡기 → 시작점 확인(3mm) → [순응 제어 + 외력 감시] 원호 `amovec(mid, via)` 15mm/s → 살며시 잡기(20mm) → 직선 `amovel` line 1, 2, end 10mm/s → 놓기(뚜껑이 받침에 걸침) → end_app으로 빠지기 → 홈

**7단계 닫기 (초안, 데모로 아직 안 해 본 동작)**: 홈 → rest_app → 툴 방향으로 들어가 rest에서 살며시 잡기 → 시작점 확인 → [순응 제어 + 외력 감시] 직선 거꾸로(end → line 2 → line 1 → via) → 꽉 잡기 → 원호 거꾸로 `amovec(mid, close_end)` → 닫히기 2도 전에 놓기 → 수직 상승 → 홈

## 5. 경첩 보호

| 장치 | 내용 | 설정값 |
|---|---|---|
| 가운데 잡기 | 잡는 점 x가 데모 시작점 x(경첩 두 개의 가운데)에서 15mm 넘게 벗어나면 시작하지 않음. 지금은 0.9mm 차이 | `COVER_MAX_AXIAL_OFFSET` |
| 고리 높이 확인 | 잡는 점이 닫힌 뚜껑 면에서 10도 넘게 벗어나면 시작하지 않음 | `COVER_MAX_GRIP_ANGLE` |
| 각도 제한 | 끝점이 92도보다 덜 열리거나(놓으면 쾅 닫힘) 받침 각도 이상이면(받침을 밂) 시작하지 않음 | `COVER_MIN_OPEN_DEG`, `COVER_REST_DEG` |
| 순응 제어 | 뚜껑을 잡고 움직이는 동안 강성 1000 N/m, 50 Nm/rad(기본값의 1/3) | `COVER_COMPLIANCE`, `COVER_STX` |
| 외력 감시 | 비동기 이동(`amovec`/`amovel`)으로 출발시키고 0.05초마다 외력을 읽음. 순응 제어를 켜고 0.3초 뒤 잰 값보다 20N 넘게 변하면 즉시 정지. 구간이 이어지면 처음 기준값을 계속 씀 | `COVER_F_LIMIT` |
| 저속 | 원호 15mm/s, 직선과 고리 접근 10mm/s | `COVER_VEL`, `COVER_LINE_VEL`, `COVER_APP_VEL` |
| 닫기 여유 | 완전히 닫히기 2도(약 7mm) 전에 놓아서 테두리에 눌러 박지 않음 | `COVER_CLOSE_MARGIN_DEG` |
| 멈췄을 때 | 무엇으로 멈춰도 그리퍼를 열지 않음(놓으면 뚜껑이 떨어짐). 순응 제어는 항상 끔. 뚜껑을 손으로 받친 뒤 그리퍼를 여세요 | |

로그에 구간마다 "최대 외력 ○N"이 남습니다. 실물에서 한 번 돌려 보고 `COVER_F_LIMIT`을 그 값 + 10N 정도로 맞추면 됩니다.

## 6. 검증

- `pytest test/test_bed_math.py test/test_cover_flow.py`: **48개 모두 통과**
- `test_cover_flow.py`는 실제 `bed_tasks`, `bed_robot`, `bed_sim` 코드를 ROS 없이 실행합니다. 가짜 세계에는 경첩 모델(고리는 경첩 원 위로만 움직이고, 40N이 넘으면 파손)과 받침이 있습니다. 놓을 때 90도를 넘었으면 받침에 걸치고, 그 전이면 "쾅 닫힘" 위반으로 기록합니다.
  - 열고 닫기 정상, 위반 0건
  - 원호를 30mm 틀어 놓으면 20N에서 정지(파손 전). 보호 장치를 끄면 가짜 경첩이 파손됨(대조 실험)
  - 원호 도중 정지 버튼을 누르면 잡은 채로 멈춤
- 두산 함수(`amovec`, `amovel`, `check_motion`, `task_compliance_ctrl`, `release_compliance_ctrl`, `get_tool_force`)는 형님 저장소의 `DSR_ROBOT2.py`에서 이름과 인자를 확인했습니다.
- **못 한 것**: ROS2를 이 환경에 설치할 수 없어서 `test/e2e_sim.py`(전체 공정)는 돌리지 못했습니다. PC에서 돌려 주세요.

## 7. 실물 전에 확인할 것

1. **고리 높이**: z 117.92(데모 시작점과 같은 높이)로 가정했습니다. 다르면 `COVER_GRIP_XYZ`의 z만 고치면 나머지는 다시 계산됩니다.
2. **받침 각도**: 실제로 붙인 각도를 `COVER_REST_DEG`에 넣으세요. 닫을 때 그 각도에서 고리를 잡습니다.
3. **순응 제어 중 비동기 이동**: 컨트롤러가 받아 주는지 에뮬레이터에서 먼저 확인하세요. 거부하면 뚜껑을 잡은 채 움직이지 않고 멈춥니다(안전한 쪽). 그때는 `COVER_COMPLIANCE = False`로 두고 외력 감시만 씁니다.
4. **툴 무게**: 순응 제어에서는 툴 무게가 틀리면 로봇이 처집니다.
5. **TCP**: 데모 좌표를 잴 때와 같은 TCP로 실행하세요(`COVER_TCP`에 이름을 넣으면 다를 때 시작을 거부합니다).
6. **첫 시험**: 한 손은 비상정지에 두세요. 닫기는 데모로 해 본 적이 없으니 특히 천천히 확인하세요.

참고: 캡처 화면의 블록 번호(2·4·6 / 1·3·5)와 코드의 번호(1 2 3 / 4 5 6)가 다릅니다. `bed_1~6`은 README 3-1의 번호대로 교시해야 기울기 계산이 맞습니다.

그리퍼 폭 메모: 살며시 잡기는 폭을 정할 수 있는 `'service'` 모드(/onrobot/sendCommand)에서만 됩니다. `'io'` 모드면 끝까지 꽉 잡은 채로 갑니다(로그에 남김). 고리 굵기에 맞춰 `cover_grip`(꽉)과 `cover_loose`(살며시)를 조정하세요. 끄려면 `COVER_LOOSE_ON_LINE = False`로 바꾸면 됩니다.
